
1. node_rrf节点实现
   公式: score_map.get(chunk_id, 0.0) + 1.0 / (k + pos) * weight
   解析: 权重 + rrf
   作用: 进行同源数据排序
   入参: embedding_chunks []  hyde_embedding_chunks  [{id:chunk_id,distance:分,entity:{} -> 最终}]
   出参: rrf_chunks [entity,entity] -> 排序 rrf + 权重
   步骤:
        1. 日志+任务
        2. 参数获取和校验 embedding_chunks hyde_embedding_chunks  get("key",[])
        3. 处理下集合参数 [(embedding_chunks,1.0),(hyde_embedding_chunks,1.0)]  -> param_list
        3. 定义个rrf+权重排序的函数  param_list  -> rrf_chunks
             1.0 / (k+rank) * weight
             3.1 定义记录分数的字典类型 / 记录存储数据的字典类型
                 score_map = {key -> chunk_id , 累计分数}  累加
                 chunk_map = {key -> chunk_id , entity}  只记录一次即可 (第一次已经存储了,不在第二存储)
             3.2 遍历 param_list 拿出某一路
                  embedding_chunks,1.0  hyde_embedding_chunks,1.0
                  3.3 再循环具体路的数据 embedding_chunks -> item (1 , 2, 3)
                       计算分数公式 score_map.get(chunk_id, 0.0) + 1.0 / (k + pos) * weight
                       如果没有记录过chunk chunk_map 存储一下
             3.3 分和数据字典都有了,对分数进行排序
             3.4 处理数据类型  [entity,entity]
             3.5 返回结果
        4. 日志+任务
        5. 返回结果 state [rrf_chunks] = 值
