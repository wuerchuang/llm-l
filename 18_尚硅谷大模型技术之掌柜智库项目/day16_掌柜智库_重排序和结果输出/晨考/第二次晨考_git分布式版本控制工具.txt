    查看:
        git log    : 查看[当前分支][有效]的[详细信息 长版本号-提交人-邮箱-时间-描述]
        git reflog : 查看本地库中[所有分支][所有操作]提交点的简单信息 短版本-提交描述

3. 写出三种版本回滚 git reset 完整命令，分别说明三种模式的差异。
    git reset --soft               软回滚,会将要删除覆盖的文件不会真的删除,放在暂存区! 用于修改message再次提交!
    git reset | git reset --mixed  混合回滚: 不会删除,将文件返回在工作区,可以分批添加暂存区或者提交! 用于文件提交错了 重新提交!
    git reset --hard               硬回滚: 删除文件和覆盖! 只保留目标提交点的内容! [git reflog]
