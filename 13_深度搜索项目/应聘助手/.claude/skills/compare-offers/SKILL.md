# Offer 对比分析

对多家公司进行多维度对比，帮助做出决策。

## 使用方式

```
/compare-offers <公司1> <公司2> [公司3...]
```

示例：
```
/compare-offers 字节跳动 美团 阿里巴巴
```

## 对比维度

一、从工作氛围上面去做分析
这个是我们最直接的看法，可以想像一下当我们去一家公司面试的时候看到每个人都是一脸冷漠或者是摆着一张苦瓜脸样的表情，这样的公司即使福利再好你会去么，必竟我们是来上班的不是来找罪受的，遇到这样的公司一定要三思而后行；

二、从他的薪资福利去做分析
就这一点而言相信是很多求职者都比较看中的一点，当然我们不能单纯的从工资上面去做比较，毕竟国营企业，民资企业，欧美企业在工资福利上都有一定差距的，你用一个国有企业和欧美企业去比工资那么肯定是欧美企业要高一点的。最关键的时候还是要看他们整体的一个待遇。

三、从公司的发展前景去做分析
这个我们不可能从面试官那里得到准确的消息，关键还是要从网上自己做市调去，我们只需要盯着他公司每一年营业额的增长率以及整个行业的增长率来看就知道这家公司有没有发展前景了。如果他是连续三年都在倒退就需要注意了。

四、从公司的会议长度去做分析
像这种都可以直接问面试官，我们平时上班要开会么，如果一天下来有一半的时间都在开会那就撤吧，现在很多的公司都把开会的时间不算做上班的时间，也就意味着你可能要加班。当然这个不是重点，重点就是屁大点的事也要开个 会议只能说明公司的办事效率普遍底下。

五、从公司的加班情况去做分析
对于现在的公司而言，要想不加班基本上是不太可能的，但是如果是自己当天的活干完了，还要求加班而且没有什么补贴，并且长期这样是不行的。像腾讯，华为这样的大公司加班到一定时间往往都有一定的加班补助的。

六、从公司的职工人数去做分析
这里说的职工人数指的是同类型的公司，比如同样是两家规模差不多大的IT企业公司，A公司的职工人数要比B公司职工人数多一半的话也就意味着如果你加人B公司可能是一个人要干两个人的活。

七、从社保方面去做分析
有些公司可能你加入该公司一年了，却还是没有缴纳社保，顾名思义是说让职工多拿点工资，但实际上你会发现其实你的薪水也就那么点，甚至可能还不如同行！

八、从公司的口碑去做分析

## 每个维度输出

- 每家公司 #1-100# 分评分
- 证据来源引用##对证据进行情感分析，标注正面/中性/负面
- 综合推荐（附理由）

## 注意事项

- 评分基于公开信息，仅供参考
- 建议与 HR 确认期权/股票的行权条件和归属期
- 考虑税后收入、社保公积金基数和城市生活成本
- 试用期长短和转正标准也是重要因素
