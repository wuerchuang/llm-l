# 面试准备

基于已经完成的公司调研报告，生成针对性的面试准备方案。

## 使用方式

```
/interview-prep <公司名> <目标岗位>
```

需要先运行 `/analyze-resume` 或 `/research-company` 获得调研数据。

## 生成内容

对每家公司生成：

### 1. 技术面试题
- 基于简历技能生成项目案例题
- 基于岗位要求生成基础理论题

### 2. 行为面试题
- 根据公司文化定制（如字节的"始终创业"、美团的"长期有耐心"）
- 根据公司风险点定制（如加班文化应对策略）

### 3. 公司特定题
- "你为什么选择 XX 公司？"
- "你对 XX 公司的业务有什么理解？"

### 4. 你应该问面试官的问题
- 团队规模和结构
- 技术栈和近期项目
- 晋升和绩效评估机制
- 对新人的期望和 onboarding 流程

### 5. 面试中应主动提及的亮点 (Talking Points)
- 2-3 个与岗位高度相关的项目案例
- 可量化的成果数据

## 面试策略提示

- 用 STAR 法则（Situation → Task → Action → Result）
- 每个案例控制在 2 分钟内
- 提前准备 1-2 个有深度的问题展示研究
- 面试前检查：直属团队、汇报对象、加班制度、薪资结构
