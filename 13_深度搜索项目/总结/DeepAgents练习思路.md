# DeepAgents 练习思路

## 1. 说明

本文基于当前 `ModelScope Skills` 与 `ModelScope MCP` 页面可见内容，筛选出更适合做 `DeepAgents` 教学演示和学生练习的方向。

筛选标准：

- 任务边界清楚，适合拆成多个子智能体
- 工具调用效果直观，便于课堂展示
- 最好能体现 `搜索 -> 分析 -> 汇总 -> 产物输出`
- 尽量避免一上来就依赖过重、过难部署的外部系统


## 2. 优先可用的能力

### 2.1 更适合参考的 Skills

这些 Skill 更偏“智能体设计思路”或“可直接演示的能力方向”：

1. `agent-browser`
   - 适合：网页操作、表单填写、页面抓取、执行型 Agent
   - 课堂价值：最容易看到“规划 -> 执行 -> 观察”的闭环

2. `agent-reach`
   - 适合：多源检索、网页调研、信息整合
   - 课堂价值：适合讲“Research Agent”

3. `agent-memory`
   - 适合：长期记忆、用户偏好保存、跨轮对话连续性
   - 课堂价值：适合讲“有记忆”和“无记忆”的差异

4. `agent-memory-systems`
   - 适合：讲记忆架构设计
   - 课堂价值：适合进阶理论课，不一定直接拿来写完整 demo

5. `agent-creator`
   - 适合：让学生练习拆 Agent、定义职责、写 prompt
   - 课堂价值：适合从“一个 Agent”过渡到“多个 Agent”

6. `agentskills`
   - 适合：做 Skill 封装、规范化输出
   - 课堂价值：适合进阶工程化训练

7. `agent-teams-playbook`
   - 适合：多 Agent 编排、团队协作
   - 课堂价值：非常适合 DeepAgents 进阶案例


### 2.2 更适合直接接入的 MCP

这些 MCP 更像“现成能用的外部能力”：

1. `Fetch 网页内容抓取`
   - 用途：抓取网页并转 markdown
   - 适合：网页研究、信息抽取、资料整理

2. `必应搜索中文`
   - 用途：中文搜索
   - 适合：Research Agent、检索增强型 Agent

3. `高德地图`
   - 用途：POI 搜索、路线规划、地图类任务
   - 适合：旅游规划、本地生活助手

4. `Chrome DevTools MCP`
   - 用途：浏览器自动化、页面检查、执行网页动作
   - 适合：自动化测试、网页操作 Agent

5. `MemOS`
   - 用途：长期记忆
   - 适合：偏好记录、跨会话 Agent、连续任务

6. `可视化图表 MCP`
   - 用途：图表生成
   - 适合：数据分析、报告输出

7. `ChatPPT MCP`
   - 用途：PPT 生成与汇报材料整理
   - 适合：从分析结果到交付物输出

8. `DeepWiki`
   - 用途：知识检索、文档型问答
   - 适合：代码文档问答、主题研究


## 3. 最推荐的练习题

下面给出 5 个最适合学生练习的方向，按“入门 -> 进阶”排列。


## 4. 练习题一：网页研究助手

### 4.1 适合程度

- 难度：低
- 推荐指数：高
- 最适合做学生第一个 DeepAgents 练习

### 4.2 核心目标

用户输入一个主题，系统自动：

- 搜索资料
- 抓取网页内容
- 提取关键信息
- 生成一份简短研究摘要

### 4.3 推荐连接

- Skill 参考：`agent-reach`
- MCP：`必应搜索中文` + `Fetch`

### 4.4 子智能体拆分

1. `search_agent`
   - 负责搜索关键词与候选网页

2. `extract_agent`
   - 负责抓取网页正文并提取信息

3. `summary_agent`
   - 负责整理最终摘要

### 4.5 基本步骤

1. 定义主智能体，只负责解析主题与调度
2. 先接入 `搜索 MCP`
3. 再接入 `网页抓取 MCP`
4. 让 `summary_agent` 输出固定结构
5. 将结果写入 `results/研究主题.md`

### 4.6 为什么适合练

- 不依赖复杂业务
- 工具调用链路清晰
- 很适合演示 `astream()` 的流式过程


## 5. 练习题二：求职投递助手

### 5.1 适合程度

- 难度：低到中
- 推荐指数：高
- 很适合做第二个练习

### 5.2 核心目标

用户输入岗位方向，系统自动：

- 搜索岗位信息
- 提取岗位要求
- 生成简历优化建议
- 输出面试题与投递建议

### 5.3 推荐连接

- Skill 参考：`agent-creator`
- MCP：`必应搜索中文` + `Fetch`

### 5.4 子智能体拆分

1. `job_agent`
   - 负责检索岗位信息和 JD

2. `resume_agent`
   - 负责根据岗位要求给出简历修改建议

3. `interview_agent`
   - 负责生成面试问题与回答提示

4. `summary_agent`
   - 负责生成最终投递方案

### 5.5 基本步骤

1. 先让主智能体抽取岗位方向、城市、薪资偏好
2. 用搜索工具找 3 到 5 个岗位样本
3. 用抓取工具提取岗位要求
4. 对要求做关键词聚合
5. 输出“岗位摘要、简历建议、面试题、投递建议”

### 5.6 为什么适合练

- 学生容易理解场景
- 输出结果容易评估
- 很适合讲“总控 + 多专家 + 汇总”


## 6. 练习题三：学习规划助手

### 6.1 适合程度

- 难度：低
- 推荐指数：高
- 适合作为课后独立练习

### 6.2 核心目标

用户输入一个学习目标，例如“2 周学会 LangChain”，系统自动：

- 拆知识点
- 找资料
- 生成日程
- 输出学习计划

### 6.3 推荐连接

- Skill 参考：`agent-creator` + `agent-memory`
- MCP：`必应搜索中文` + `Fetch` + `MemOS`

### 6.4 子智能体拆分

1. `knowledge_agent`
   - 负责拆知识点

2. `resource_agent`
   - 负责搜资料

3. `schedule_agent`
   - 负责按时间生成计划

4. `memory_agent`
   - 负责记录用户偏好和学习进展

### 6.5 基本步骤

1. 主智能体提取学习目标、周期、基础水平
2. 知识点子智能体先做知识树拆解
3. 资料子智能体找教程、文档、视频
4. 日程子智能体生成每日安排
5. 记忆模块记录“已学内容”和“偏好节奏”

### 6.6 为什么适合练

- 外部依赖相对少
- 非常适合加入“长期记忆”
- 容易做连续多轮演示


## 7. 练习题四：网页操作助手

### 7.1 适合程度

- 难度：中
- 推荐指数：高
- 很适合做执行型 Agent 演示

### 7.2 核心目标

用户输入网页任务，系统自动：

- 打开网页
- 定位页面元素
- 执行动作
- 返回执行结果

### 7.3 推荐连接

- Skill 参考：`agent-browser`
- MCP：`Chrome DevTools MCP`

### 7.4 子智能体拆分

1. `planner_agent`
   - 负责把网页任务拆成若干动作

2. `browser_agent`
   - 负责执行浏览器操作

3. `review_agent`
   - 负责检查动作结果是否成功

### 7.5 基本步骤

1. 主智能体先把用户需求拆成步骤
2. 浏览器子智能体负责逐步执行
3. 每一步都返回页面状态
4. 审查子智能体判断是否继续或回退
5. 最终输出执行日志

### 7.6 为什么适合练

- 最能体现 Agent 的行动能力
- 非常适合课堂实时展示
- 能清楚讲“观察 -> 决策 -> 执行 -> 反馈”


## 8. 练习题五：数据分析汇报助手

### 8.1 适合程度

- 难度：中到高
- 推荐指数：高
- 适合作为综合练习

### 8.2 核心目标

用户输入一个主题或数据，系统自动：

- 搜集背景信息
- 生成分析摘要
- 产出图表
- 生成 PPT 或汇报提纲

### 8.3 推荐连接

- Skill 参考：`agent-teams-playbook`
- MCP：`Fetch` + `可视化图表 MCP` + `ChatPPT MCP`

### 8.4 子智能体拆分

1. `research_agent`
   - 负责收集背景材料

2. `analysis_agent`
   - 负责提炼分析结论

3. `chart_agent`
   - 负责生成图表

4. `report_agent`
   - 负责生成 PPT 提纲或汇报稿

### 8.5 基本步骤

1. 主智能体定义报告主题
2. 调用搜索和抓取能力收集资料
3. 分析子智能体形成结构化结论
4. 图表子智能体输出图表
5. 汇报子智能体输出 PPT 结构

### 8.6 为什么适合练

- 最容易形成“可交付成果”
- 非常适合做课程大作业
- 能完整展示 DeepAgents 的工程价值


## 9. 与当前旅游规划案例的衔接建议

你现在已经讲了 `旅游规划助手`，后续最顺的安排是：

1. `旅游规划助手`
   - 讲清楚多智能体基本结构

2. `网页研究助手`
   - 让学生练“搜索 + 抓取 + 汇总”

3. `学习规划助手`
   - 让学生练“加入记忆”

4. `网页操作助手`
   - 让学生练“会执行动作”

5. `数据分析汇报助手`
   - 让学生练“形成最终产物”


## 10. 教学上最推荐的三组组合

### 10.1 入门组合

- `必应搜索中文`
- `Fetch`

适合：

- 网页研究助手
- 求职投递助手
- 学习规划助手


### 10.2 实战组合

- `高德地图`
- `Fetch`

适合：

- 旅游规划助手
- 本地生活助手


### 10.3 进阶组合

- `MemOS`
- `Chrome DevTools MCP`
- `可视化图表 MCP`

适合：

- 记忆型 Agent
- 执行型 Agent
- 产物型 Agent


## 11. 给学生的统一开发模板

建议所有练习都按同一套路完成：

1. 先定义一个主智能体
2. 再拆 2 到 4 个子智能体
3. 至少接 1 个外部能力
4. 用 `astream()` 做流式输出
5. 把最终结果写到 `results/xxx.md`

建议统一目录：

```text
project/
├── app.py
├── agents/
│   ├── main_agent.py
│   ├── sub_agent_a.py
│   ├── sub_agent_b.py
│   └── summary_agent.py
├── config/
│   └── memory/
│       └── AGENTS.md
├── results/
└── requirements.txt
```


## 12. 最终推荐

如果只选 3 个最值得学生练的题目，我建议：

1. `网页研究助手`
   - 最容易跑通

2. `学习规划助手`
   - 最适合加入记忆

3. `求职投递助手`
   - 最适合做多智能体分工展示

如果要做 1 个进阶综合项目，我建议：

- `数据分析汇报助手`

因为它最完整，能体现：

- 搜索
- 抽取
- 分析
- 图表
- 汇报输出
