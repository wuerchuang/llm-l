# 第2章 搭建基础设施

## 2.1 配置文件

本项目使用 `pydantic-settings` 作为配置管理工具，具体用法可参考[FastAPI教程](https://fastapi.tiangolo.com/zh/advanced/settings/)。

具体做法如下：

在项目的根目录创建`.env` 配置文件，并添加如下配置参数：

```shell
LLM_MODEL=qwen-plus
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_API_KEY=sk-xxxxxxxxxx

COMMERCE_API_BASE_URL=http://127.0.0.1:18081

DATABASE_URL=mysql+aiomysql://root:123456@127.0.0.1:3306/customer_service?charset=utf8mb4

APP_HOST=0.0.0.0
APP_PORT=18082
```

在 `atguigu.conf` 包下创建 `config.py` 文件，并编写如下代码：

```python
from pathlib import Path
from pydantic_settings import BaseSettings, SettingsConfigDict

# load_dotenv()
# os.getenv("LLM_MODEL")
# 获取当前文件上两层目录，找到.env文件
ENV_DIR = Path(__file__).parents[2]
ENV_FILE = ENV_DIR / '.env'

class Settings(BaseSettings):
    # 加载配置文件，读取值，赋值当前对应变量里面
    # 使用变量接受，特殊：变量名称固定的 model_config
    model_config = SettingsConfigDict(
        # 文件位置
        env_file=ENV_FILE,
        # 编码方式，中文
        env_file_encoding='utf-8',
        # 配置文件属性和类属性不一致
        extra='ignore'
    )
    # 对应配置文件，创建对应属性:类型
    LLM_MODEL:str

    llm_api_key: str
    llm_base_url: str

    # 数据库
    database_url: str
    # 商城 API
    commerce_api_base_url: str
    # 服务器
    app_host: str
    app_port: int

settings = Settings()

if __name__ == '__main__':
    print(settings.LLM_MODEL)
    print(settings.app_host)
```

## 2.2 客户端

### 2.2.1 LLM客户端

本项目使用 `langchain` 的 `init_chat_model` 构造LLM客户端，具体用法可参考[langchain官网](https://reference.langchain.com/python/langchain/chat_models/base/init_chat_model)。

具体做法如下：

在 `atguigu.clients` 包下创建 `llm_client.py`，并编写如下代码：

```python 
from traceback import print_tb

from langchain.chat_models import init_chat_model
from langchain_core.language_models import BaseChatModel

from atguigu.config.config import settings

# 创建llm对象
llm:BaseChatModel = init_chat_model(
    model=settings.LLM_MODEL,
    model_provider="openai",
    api_key=settings.llm_api_key,
    base_url=settings.llm_base_url,
    temperature=0,
)

if __name__ == "__main__":
    print(llm.invoke("hello").content)
```

### 2.2.2 Database客户端

本项目使用 `SQLAlchemy` 创建 Database客户端，具体用法可参考[SQLAlchemy官网](https://docs.sqlalchemy.org/en/20/index.html)。

具体做法如下：

在 `atguigu.clients` 包下创建 `database.py` ，并编写如下代码：

```python
import asyncio

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine, AsyncSession, async_sessionmaker, create_async_engine

from atguigu.config.config import settings

# 定义变量
engine: AsyncEngine | None = None
async_session: async_sessionmaker[AsyncSession]

# 初始化两个对象的方法
def init_db_engine():
    global engine,async_session
    # engine异步对象
    engine = create_async_engine(
        settings.database_url,
        echo=True,
    )
    # 通过session工厂创建session会话
    async_session = async_sessionmaker(
        engine,expire_on_commit=False
    )

# 关闭的异步方法
async def close_engine():
    await engine.dispose()

# 测试方法
async def test():
    init_db_engine()

    # 通过session工厂获取session对象，基于session里面engine数据库操作
    async with async_session()  as session:
        result = await session.execute(text("select 1"))
        print(result.fetchone())
    await close_engine()

if __name__ == '__main__':
    asyncio.run(test())
```

### 2.2.3 Http客户端

本项目使用 `HTTPX` 创建 Http 客户端，具体用法可参考 [HTTPX 官网](https://www.python-httpx.org/) 。

具体做法如下：

在 `atguigu.clients` 包下创建 `http.py` ，并编写如下代码：

```python
import asyncio
from httpx import AsyncClient

# 定义变量
http_client:AsyncClient | None = None

# 初始化方法
def init_http_client():
    global http_client
    http_client = AsyncClient(timeout=10.0)

# 关闭的方法
async def close_http_client():
    await http_client.aclose()

# 测试调用的方法
async def test():
    init_http_client()
    response = await http_client.get(
        url="http://127.0.0.1:18081/users/u1001/orders")
    print(response.json())

if __name__ == "__main__":
    asyncio.run(test())
```



# 第3章 实现接口框架

## 3.1 接口定义

客服后端需提供两个接口，分别是 `/api/chat` 和 `/api/chat/history` ，前者用于回复用户消息，后者用于获取聊天历史记录。

两个接口的定义如下：

### 3.1.1 POST `/api/chat`

发送一条用户消息，返回机器人本轮回复。

#### 请求体

```json
{
  "sender_id": "user_001",
  "text": "帮我查一下订单状态",
  "object": null,
  "message_id": "msg_001"
}
```

#### 字段说明

| 字段         | 类型             | 必填 | 说明                                |
| ------------ | ---------------- | ---- | ----------------------------------- |
| `sender_id`  | `string`         | 是   | 用户唯一标识                        |
| `text`       | `string \| null` | 否   | 用户文本消息                        |
| `object`     | `object \| null` | 否   | 用户结构化对象消息                  |
| `message_id` | `string \| null` | 否   | 客户端消息 ID；不传时服务端自动生成 |

#### `object` 字段

| 字段         | 类型             | 必填 | 说明                            |
| ------------ | ---------------- | ---- | ------------------------------- |
| `type`       | `string`         | 是   | 对象类型，如 `order`、`product` |
| `id`         | `string`         | 是   | 对象 ID                         |
| `title`      | `string \| null` | 否   | 对象标题                        |
| `attributes` | `object`         | 否   | 扩展属性，默认空对象            |

对象消息请求示例：

```json
{
  "sender_id": "user_001",
  "text": null,
  "object": {
    "type": "order",
    "id": "ORDER_10001",
    "title": "订单 ORDER_10001",
    "attributes": {
      "source": "order_list"
    }
  },
  "message_id": "msg_002"
}
```

#### 请求约束

- `sender_id` 必填
- `text` 和 `object` 必须且只能传一个
- `text` 不能是空字符串或只包含空白字符
- 若传 `object`，则 `object.type` 和 `object.id` 必填

#### 响应体

```json
{
  "sender_id": "user_001",
  "message_id": "msg_001",
  "messages": [
    {
      "text": "好的，我们先处理订单状态查询。",
      "object": null
    },
    {
      "text": "请告诉我你的订单号。",
      "object": null
    }
  ]
}
```

#### 响应字段

| 字段         | 类型     | 必填 | 说明               |
| ------------ | -------- | ---- | ------------------ |
| `sender_id`  | `string` | 是   | 用户唯一标识       |
| `message_id` | `string` | 是   | 本次消息 ID        |
| `messages`   | `array`  | 是   | 机器人本轮回复列表 |

#### `messages[]` 字段

| 字段     | 类型             | 必填 | 说明                              |
| -------- | ---------------- | ---- | --------------------------------- |
| `text`   | `string \| null` | 否   | 回复文本                          |
| `object` | `object \| null` | 否   | 回复对象，结构同请求中的 `object` |

#### 状态码

- `200 OK`
- `422 Unprocessable Entity`：请求体不符合字段类型或消息内容约束

### 3.1.2 GET `/api/chat/history`

获取指定用户的聊天历史。

#### Query 参数

| 参数        | 类型     | 必填 | 说明         |
| ----------- | -------- | ---- | ------------ |
| `sender_id` | `string` | 是   | 用户唯一标识 |

#### 请求示例

```http
GET /api/chat/history?sender_id=user_001
```

#### 响应体

```json
{
  "sender_id": "user_001",
  "messages": [
    {
      "role": "user",
      "text": "帮我查一下订单状态",
      "object": null
    },
    {
      "role": "bot",
      "text": "好的，我们先处理订单状态查询。",
      "object": null
    },
    {
      "role": "bot",
      "text": "请告诉我你的订单号。",
      "object": null
    }
  ]
}
```

#### 响应字段

| 字段        | 类型     | 必填 | 说明         |
| ----------- | -------- | ---- | ------------ |
| `sender_id` | `string` | 是   | 用户唯一标识 |
| `messages`  | `array`  | 是   | 历史消息列表 |

#### `messages[]` 字段

| 字段     | 类型            | 必填 | 说明                              |
| -------- | --------------- | ---- | --------------------------------- |
| `role`   | `string`        | 是   | `user`、`bot`                     |
| `text`   | `string | null` | 否   | 消息文本                          |
| `object` | `object | null` | 否   | 对象消息，结构同请求中的 `object` |

#### 状态码

- `200 OK`
