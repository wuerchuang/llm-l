## 第1章 LangChain概述

### 1.1 什么是LangChain

模型调用工具，统一异构模型的不同API，做到一套API调用所有模型，任务编排组件，开发大模型应用程序

### 1.2 为什么要学习LangChain

1. 模型本身存在短板，无法实现联网搜索，外部工具调用，对话记忆存储等功能，而LangChain提供这些能力

2. 统一市面上模型调用的接口，为程序员提供简洁、通用、易于维护的语法结构

### 1.3 LangChain的四大模块

Model I/O、Chains、RAG、Agents

##### DEBUG日志

开启日志的debug级别后： 会发现日志的请求参数中一个选项 `idempotency_key` 幂等键

```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

**幂等：**同一个请求重复发送N次，效果和只发1次完全一样，不会产生重负调用所引起的副作用

如何实现幂等调用：设置一个幂等键，是一个全局唯一的字符串，例如，在openai的调用中，幂等键大致如下

stainless-python-retry-990d27fd-c1a7-49df-8c35-65d46b07ca66，用来标记一次完整的业务请求

如果请求中携带了同一个幂等键，那么就是重试请求，服务端识别这是重复请求，直接返回上一次已生成好的结果，不重新推理，不计费不重复生成内容

### 3.4 使用LangChain

参考文档：https://docs.langchain.com/oss/python/langchain/quickstart

基本方式：使用 init_chat_model 初始化模型客户端对象，然后invoke方法通过非流式的方式调用模型

3.4.1 基本调用

参数传递：

```python
load_dotenv()

#方式1：
model = init_chat_model("openai:deepseek-v4-flash")


#方式2：
model = init_chat_model(
    model = "deepseek-v4-flash",
    model_provider="openai"
)

model.invoke(input="字符串")
```
