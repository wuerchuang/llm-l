2、使用过滤命令，从`/etc/passwd`中筛选出包含 root 的行。

```shell
grep "root" /etc/passwd
```

3、打包压缩 project 整个目录为`project.tar.gz`，之后解压到 /tmp 目录。

```shell
tar -czvf project.tar.gz project
```

```shell
tar -xzvf project.tar.gz -C  /tmp
```
