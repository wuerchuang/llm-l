# 第 1 章 VMware

## 1.1 VMware Workstation简介

简称“VMware”，VMware Workstation 是一款由 VMware 公司开发的虚拟化软件，它允许用户在一台物理机器上创建和运行多个完整的虚拟机。每台虚拟机可以运行不同的操作系统，并且与主机系统和其他虚拟机之间保持良好的隔离性。

### 11、选择磁盘的类型

![image-20260110122917912](images/image-20260110122917912.png)

> 四种类型详解与选择建议

| 类型     | 兼容性   | 性能           | 推荐使用场景                                                 |
| :------- | :------- | :------------- | :----------------------------------------------------------- |
| **IDE**  | **最高** | **最差**       | **Windows XP及更老的系统**；某些无法识别SCSI驱动的古董操作系统安装盘。 |
| **SCSI** | **高**   | **高**         | **VMware的默认推荐**，适用于绝大多数现代服务器和桌面系统（Windows/Linux）。 |
| **SATA** | **中**   | **高**         | Windows 7/Vista及之后、Linux 2.6.19内核及之后的系统。性能与SCSI相当。 |
| **NVMe** | **低**   | **理论上最高** | **Windows 10/11， Server 2016+， 现代Linux发行版**。需系统内置驱动，追求极致性能。 |

> 为什么VMware“推荐SCSI”？（即使宿主机是SATA）

**VMware推荐SCSI，不是因为它物理上更快，而是因为它在虚拟化环境中的综合优势：**

1. **功能最全**：SCSI控制器支持高级功能，如**热添加磁盘**（在不断机的情况下给虚拟机增加新硬盘）、更高效的中断处理。
2. **队列深度高**：能更好地处理并发I/O请求，在多任务负载下表现更优。
3. **兼容性极佳**：所有现代操作系统（Windows/Linux/Unix）都自带稳定可靠的SCSI驱动，开箱即用。
4. **管理生态成熟**：VMware的全套工具链（快照、Storage vMotion、备份）对SCSI虚拟磁盘的支持和优化最成熟。
5. **性能不差**：在虚拟化层面，经过高度优化的SCSI控制器性能与SATA/NVMe模拟控制器在实际使用中感知差距不大，除非你进行极端基准测试。

**简单比喻**：SCSI就像一个经验丰富、功能全面的“老司机”，虽然开的车（模拟的）牌子不是最新款，但他熟悉所有道路和交通规则（VMware虚拟化层），能最安全、稳定、高效地把你的数据送到目的地。而NVMe模拟的控制器就像一个开超级跑车的新手，车本身潜力巨大，但可能在复杂的立交桥（虚拟化环境）上找不到最佳路线。

> SATA与SSD关系？

| 维度                | **SATA**                                                     | **SSD**                                                      |
| :------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **本质是什么**      | **一种接口/通道标准**                                        | **一种存储介质/设备类型**                                    |
| **类比**            | **公路的类型**（如：省道、国道、高速公路）                   | **车的类型**（如：卡车、跑车）                               |
| **核心功能**        | 负责在**主板**和**存储设备**之间传输数据。定义物理连接器形状、电缆和通信协议。 | 用于**永久存储数据**。使用闪存芯片（NAND Flash）而非机械盘片来读写数据。 |
| **对立/对比的对象** | 与 **IDE/PATA**（上一代）、**SAS**（企业级）、**NVMe/PCIe**（新一代）等接口标准对比。 | 与 **HDD** 进行对比。HDD 是另一种存储设备类型（机械硬盘）。  |

| 存储设备类型        | 可能使用的接口/通道 | 性能比喻                                                   |
| :------------------ | :------------------ | :--------------------------------------------------------- |
| **HDD（机械硬盘）** | SATA（最常见）      | **拖拉机走国道**。国道限速远高于拖拉机速度，毫无压力。     |
| **SSD（固态硬盘）** | SATA                | **跑车走国道**。跑车性能被国道限速压制，无法发挥全部实力。 |
| **SSD（固态硬盘）** | **NVMe/PCIe**       | **跑车走高速公路**。路快、协议高效，跑车性能得到彻底释放。 |

### 2.2.4 配置网络

在未进行自定义网络配置前，当前虚拟机就已经可以通过宿主系统（Windows）连接外网了。当前配置网络并不是为了让虚拟机能上网。

❓问题：当前虚拟机在宿主机上的`内网`虚拟IP是动态产生的，而宿主机想要连接虚拟机需要确定虚拟机的IP地址才能连接，动态变化的IP极不方便。

✅解决：接下来通过相关网络配置来固定虚拟机的`内网`虚拟IP。

![image-20260110171315003](images/image-20260110171315003.png)

#### 1、固定虚拟机的内网虚拟IP

（1）选择VMware的【编辑】菜单->【虚拟网络编辑器(N)...】

![image-20260110165508719](images/image-20260110165508719.png)

（2）弹出虚拟网络编辑窗口，选择【更改设置】

![image-20260110165700222](images/image-20260110165700222.png)

（3）设置子网IP

🔴如果当前教室网段是10，这里就要修改为其他网段

🔴子网IP：192.168.x.0，最后一位“0”是子网地址的常规写法，不能随意更改。例如：`192.168.10.0` 在这里表示一个**子网地址**，而不是一个可用的IP地址，这个写法表示：

- 网络地址：192.168.10.0
- 可用IP范围：192.168.10.1 - 192.168.10.254
- 广播地址：192.168.10.255

![image-20260110165947379](images/image-20260110165947379.png)

> 三种模式对比总览

| 特性               | **桥接模式**                                             | **NAT模式 (VMnet8)** | **仅主机模式 (VMnet1)** |
| :----------------- | :------------------------------------------------------- | :------------------- | :---------------------- |
| **网络位置**       | 同宿主机物理网络（会占用教室网络IP，与某学生电脑IP冲突） | 独立虚拟网络         | 独立虚拟网络            |
| **IP分配**         | 物理网络DHCP                                             | 虚拟网络DHCP         | 虚拟网络DHCP            |
| **访问宿主机**     | ✅ 直接                                                   | ✅ 通过虚拟网络       | ✅ 通过虚拟网络          |
| **访问其他物理机** | ✅ 直接                                                   | ❌ 不能直接           | ❌ 不能直接              |
| **访问Internet**   | ✅ 直接                                                   | ✅ 通过NAT转换        | ❌ 不能                  |
| **被外部访问**     | ✅ 直接可达                                               | ❌ 需端口转发         | ❌ 完全隔离              |
| **网段要求**       | 与物理网络同网段                                         | 与物理网络不同       | 任意设置                |

> 🔧 如何确定网关IP？

- 家用路由器：通常是 `.1`
- 企业防火墙：可能是 `.254` 或 `.1`
- VMware虚拟网络：默认 `.2`

网关IP必须满足：

1. **在同一子网内**：192.168.10.1 - 192.168.10.254
2. **不能是网络地址**：不能是 192.168.10.0
3. **不能是广播地址**：不能是 192.168.10.255
4. **不能与已有设备冲突**
