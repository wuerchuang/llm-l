## 试题

1. 简述命令 `apt update` 的核心作用，它会不会直接安装 / 升级软件包？

   ```
   不会，它只是更新应用列表。更新的是应用的索引（下载的URL），版本等信息。
   ```

   ```
   apt upgrade           不会删除旧的软件包，轻量级的升级
   apt full -upgrade      删除旧的软件包，安装更新的软件包，重量级的升级
   ```

   `apt install nginx` 作用是什么？如果想要不交互自动确认安装，需要补充什么参数？

2. 简述 `pwd` 命令的功能。

   ```
   打印当前的工作目录
   ```

   

3. `ls -l` 相比普通`ls`，额外实现了什么作用？

   ```
   ls 精简版的列出当前目录下的文件，或文件夹
   ls -l，l表示long，长数据格式，包含文件或目录的类型、权限、用户、组、大小等信息
   
   ll  等价于  ls -al，这里a代表的是all，包含.(当前目录）和..（上级目录）这2个特殊目录，以及一下隐藏的文件或目录。
   ```

   

4. `cd ~`、`cd ..` 两条命令分别代表切换到什么目录？

   ```
   cd ~：跳转到当前用户目录下
   cd ..：表示回到上级目录
   
   cd -：回到上一次目录
   cd /：回到根目录
   ```

   

5. 创建多级嵌套目录（如 /a/b/c）时，`mkdir` 需要搭配哪个参数？

   ```
   mkdir 一级目录
   mkdir -p 多级目录
   ```

   

6. `touch test.txt` 这条命令的主要用途是什么？

   ```
   touch 文件名.扩展名  创建不存在的空文件
   
   touch 已存在的文件.扩展名   不会创建一个空文件，即不会覆盖
   ```

   

7. 复制文件夹目录时，`cp` 必须添加哪个参数才能递归复制目录？

   ```
   cp -r 原来的目录 复制后的目录
   ```

   

8. 简述 `rm -rf 目录名` 中 `-r` 和 `-f` 两个参数各自的作用。

   ```
   -r：递归删除目录
   -f：强制删除目录，不询问
   ```

   

9. `mv old.txt new.txt` 和 `mv test.txt /tmp/` 两种写法分别实现什么操作？

   ```
   mv old.txt new.txt  对文件重命名
   mv test.txt /tmp/   把test.txt移动到/tmp/目录下
   ```

   

10. `cat` 和 `tail -n 5` 在查看文件上有什么区别？

    ```
    cat 文件名.扩展名   查看文件的所有内容
    tail -n 5 文件名.扩展名 查看文件的最后5行内容
    ```

    

复习：

```
apt remove 包 		删除具体软件包
apt autoremove 包    删除该具体包及其依赖的其他包，或者删除残余的孤儿（之前依赖的包以及删除了）

apt install 包

apt upgrade           不会删除旧的软件包，轻量级的升级
apt full -upgrade      删除旧的软件包，安装更新的软件包，重量级的升级

apt list 包    
apt list 		列出所有可以下载的包，列出应用列表
apt search 包 #支持模糊查询
apt show 包  详细查看说明书
```

```
往文件写东西？
cat > 文件名.扩展名  覆盖模式把在终端输入的内容写到文件中
cat >> 文件名.扩展名 追加模式把在终端输入的内容写到文件中
vim 文件名.扩展名     类似于用专门的文件编辑器（类似于记事本、notepadd++等）打开文件编辑（今天再讲）
echo 内容 > 文件名.扩展名  直接把内容写到文件中，覆盖
echo 内容 >> 文件名.扩展名  直接把内容写到文件中，追加
```

```
rm 文件名.扩展名  删除文件
rm -r 目录  删除目录
   -v  详细显示删除过程
   -f  强制删除
```
