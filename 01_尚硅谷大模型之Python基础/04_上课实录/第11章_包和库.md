#### 题目1：提取手机号码

**描述**：从给定的文本中提取所有的中国手机号码。要求：

- 11位数字
- 以1开头
- 第二位是3-9之间的数字

```
输入："我的电话是13812345678，朋友的电话是15987654321"
输出：['13812345678', '15987654321']
```

```python
text = "我的电话是13812345678，朋友的电话是15987654321"
pattern = r"((13[0-9]|14[01456879]|15[0-35-9]|16[2567]|17[0-8]|18[0-9]|19[0-35-9])\d{8})"
result = re.findall(pattern, text)
print("所有的手机号码：")
for tel,_ in result:
    print(tel,end=' ')
```

#### 题目3：验证密码强度

**描述**：验证密码是否符合以下要求：

- 至少8个字符
- 至少包含一个大写字母
- 至少包含一个小写字母
- 至少包含一个数字
- 至少包含一个特殊字符（@#$%^&+=）

```
输入：Password123@
输出：True

输入：weakpassword
输出：False
```

```python
passwords = [
    "K3#pR8$q",
    "W9&vN2@m",
    "X5^gL7#s",
    "B2@dF4%j",
    "Y7+uM1&t",
    "H8=zC3^e",
    "Tabcdedf",
    "M6%rJ9+v",
    "P1#cA5@y",
    "V3&12345"
]
pattern = "^((?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@#$%^&+=])[a-zA-Z\d@#$%^&+=]{8,})$"
for password in passwords:
    print(password,"合法" if re.match(pattern,password) else "不合法")

```



#### 题目4：验证身份证号码

**描述**：验证18位中国身份证号码的格式。要求：

- 前17位必须是数字
- 最后一位可以是数字或X或x
- 包含出生日期部分（第7-14位）
- 验证出生日期是否有效（简单验证月份和日期范围）

```python
mock_id_cards = [
```

#### 题目5：格式化电话号码

**描述**：将不同格式的电话号码统一格式化为标准形式。输入的电话号码可能包含空格、横线、括号等：

- 手机号码：统一为XXXXXXXXXX

- 电话号码：统一为(区号)XXXXXXX

  手机号码：- 11位数字，以1开头，第二位是3-9之间的数字
  座机号码规则：3位/4位区号-7/8位电话号码

```
输入：137 8968 9685 输出：13789689685
输入：137-8968-9685 输出：13789689685
输入：1378-9689-685 输出：13789689685
输入：13789689685 输出：13789689685
输入：(010)89689685 输出：(010)89689685
输入：010-89689685 输出：(010)89689685
输入：0571-8968593 输出：(0571)8968593
```

```python
tels = ['137 8968 9685',
        '137-8968-9685',
        '1378-9689-685',
        '13789689685',
        '(010)89689685',
        '010-89689685',
        '0571-8968593']
pattern_phone1 = r"((13[0-9]|14[01456879]|15[0-35-9]|16[2567]|17[0-8]|18[0-9]|19[0-35-9])[ -]?\d{4}[ -]?\d{4})"
pattern_phone2 = r"((13[0-9]|14[01456879]|15[0-35-9]|16[2567]|17[0-8]|18[0-9]|19[0-35-9])\d[ -]?\d{4}[ -]\d{3})"
pattern_tel1 = r"^[(](0\d{2,3})[)](\d{7,8})$"
pattern_tel2 = r"^(0\d{2,3})-?(\d{7,8})$"
for t in tels:
    if re.match(pattern_phone1, t) or  re.match(pattern_phone2, t) or re.match(pattern_tel1,t) or re.match(pattern_tel2,t):
        print(t, re.sub('[ -]',"", t))
```
