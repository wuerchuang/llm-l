### 题目1：列表转字典

```
keys = ["name", "age", "gender"]
values = ["小李", 22, "男"]
```

将两个列表转换成一个字典。

### 题目 2：函数定义与调用

定义一个函数 calculate，它接受两个整数参数 a 和 b，返回这两个数的商和余数，并调用该函数计算 15和4的商和余数。如果b为0，则商和余数为None。

### 题目 3：默认参数

定义一个函数 greet，它接受一个字符串参数 name，并且有一个默认参数 message，默认值为 "Hello"，函数功能是打印出问候语，如 "Hello, Alice"。调用该函数时，分别传入和不传入 message 参数进行测试。

### 题目 4：可变参数

定义一个函数 find_all_even，它接受任意数量的整数参数，返回所有参数中的偶数。例如调用 find_all_even(1, 2, 3, 4, 5) 应返回 [2,4]。
