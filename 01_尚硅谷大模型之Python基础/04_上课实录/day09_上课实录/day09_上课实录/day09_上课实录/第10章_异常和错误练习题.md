## 练习题1：成绩计算器

**题目描述：**
编写一个程序，让用户输入学生的考试成绩（整数），然后计算这些成绩的平均分。程序需要：

- 循环接收用户输入的成绩，输入"结束"时停止输入
- 使用try-except处理输入错误（非整数输入）
- 当输入非整数时，提示"输入无效，请输入整数"
- 使用else子句在成功输入时累加成绩
- 使用finally子句在每次输入后打印"当前已输入 X 个有效成绩"
- 最后显示平均分（保留两位小数）

```python
total = 0
count = 0
while True:
    try:
        score_str = input("请输入考试成绩（整数）：")
        if score_str == "结束": #因为字符串str重写了 __eq__方法，可以按照字符串的内容进行比较是否相等
            break
        score = int(score_str)

        count += 1
    except ValueError:
        print("输入无效，请输入整数")
    else:
        total += score
    finally:
        print(f"当前已输入{count}个有效成绩")

# print(f"平均分：{total/count:.2f}")
print(f"平均分：{round(total/count)}")
```



## 练习题2：列表元素访问器

**题目描述：**
创建一个包含10个随机整数的列表（1-100之间）。让用户输入索引值来访问列表中的元素。程序需要：

- 预设列表：`numbers = [23, 45, 67, 89, 12, 34, 56, 78, 90, 21]`
- 让用户输入索引（整数）
- 使用try-except处理两种异常：
  - 输入不是整数时，提示"请输入整数索引"
  - 索引超出范围时，提示"索引超出范围，有效范围是0-9"
- 使用else子句在成功访问时显示该位置的元素
- 使用finally子句显示"索引访问尝试完成"
- 程序持续运行直到用户输入"退出"

```python
numbers = [23, 45, 67, 89, 12, 34, 56, 78, 90, 21]
while True:
    try:
        index_str = input("请输入索引：")
        if index_str == "退出":
            break
        index = int(index_str)
        if index<0 or index>=len(numbers):
            raise IndexError("索引超出范围，有效范围是0-9")
    except ValueError:
        print("请输入整数索引")
    except IndexError as e:
        print(e)
    else:
        print(f"[{index}]位置的元素是{numbers[index]}")
    finally:
        print("索引访问尝试完成")
```
