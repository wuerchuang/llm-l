编写一个函数，接收一个由**数字组成的字符串**（例如 `"12345"`），完成以下功能：

1. 将字符串中的每个字符转为整数，存入列表
2. 计算列表中所有数字的**平均值**（保留 2 位小数）
3. 计算列表中所有数字的**几何平均数**
4. 返回：平均值、几何平均数

## 题目2：词频统计

给定一段英文文本（包含大小写、标点），完成：

1. 去掉所有标点符号
2. 全部转为小写
3. 按单词统计**出现次数**（使用 Counter）
4. 使用 defaultdict 统计**首字母相同的单词列表**

```
"Hello world! Hello Python. Python is fun, fun fun. Wow!"
```

```
单词频次： {'fun': 3, 'hello': 2, 'python': 2, 'world': 1, 'is': 1, 'wow': 1}
首字母分组： {'w': ['wow', 'world'], 'i': ['is'], 'h': ['hello'], 'f': ['fun'], 'p': ['python']}
```

## 题目3：双端队列滑动窗口（算法题，难）

定义函数`sliding_max(nums:list, k:int)`给定一个列表和一个窗口大小 k，使用 **deque** 实现**滑动窗口最大值**。

```
列表：[1,3,-1,-3,5,3,6,7]
窗口大小 k=3
输出：[3,3,5,5,6,7]
```
