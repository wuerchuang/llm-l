## 题3：装饰器

1、维护一个全局的用户登录字典`login_dict`，key是账号ID，value是登录时间

2、创建一个装饰器函数`login_required`，用于检测是否登录。如果id在字典中，表示已登录，否则就是未登录。

3、定义BankAccount类，

（1）包含实例属性：账号`id`和余额`balance`

（2）存款`withdraw(self,money)`函数

（3）取款`deposit(self,money)`函数

（4）查询余额`query(self)`函数

4、给存款、取款、查询余额的函数加装饰器 `@login_required`

1. 如果用户未登录，抛出自定义异常NonLoginError("请先登录")
2. 如果用户已登录，正常执行被装饰函数

5、基于以下代码进行编写

> 以下是BankAccount类

```python
login_dict = {}
class BankAccount:
    def __init__(self,id):
        self.id = id
        self.balance = 0
    def withdraw(self,money):
        if money<=0:
            print("取款金额必须为正数")
        elif money > self.balance:
            print("余额不足")
        else:
            self.balance -= money

    def deposit(self,money):
        if money<=0:
            print("存款金额必须为正数")
        else:
            self.balance += money

    def query(self):
        return self.balance
```
