### 1. 列表操作

1. 创建一个列表 `nums = [1,2,3,4,5]`，在列表**末尾**添加数字 6，在**开头**插入数字 0。
2. 列表 `lst = [10,20,30,20,40,20]`，删除列表中**第一个** 20。
3. 计算列表 `scores = [88,92,76,90,85]` 的**总和**和**平均值**。
4. 反转列表 `lst = [1,2,3,4]`（直接修改原列表）。
5. 列表 `fruits = ["apple","banana","orange"]`，判断 `"apple"` 是否在列表中。

### 2. 集合操作

1. 创建集合 `s1 = {1,2,3,4}` 和 `s2 = {3,4,5,6}`，求两个集合的**交集**。
2. 向集合 `s = {1,2}` 中添加元素 3，删除元素 1。
3. 判断集合 `a = {1,2}` 是否是集合 `b = {1,2,3}` 的**子集**。
4. 有两个列表 `lst1 = [1,2,3,4]`、`lst2 = [3,4,5,6]`，找出**两个列表中都存在的元素**。
5. 去除列表 `lst = [5,2,5,1,2,1,3]` 中的重复元素，并**从小到大排序**。

### 3. 字符串操作

1. 定义字符串 `s = "Hello Python 123"`，统计字符串中**字母**的个数。
2. 给定字符串 `name = "  python learner  "`，去除首尾空格，并将所有字母转为大写。
3. 截取字符串 `s = "abcdefg"`，输出**第 3 个到第 6 个字符**（包含两端）。
4. 判断字符串 `tel = "13800138000"` 是否**全部由数字组成**。
5. 将字符串 `words = "python-java-c++"` 按照 `-` 分割，得到列表。
