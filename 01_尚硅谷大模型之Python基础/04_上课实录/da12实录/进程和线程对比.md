# 进程和线程对比

| 创建方式       | 进程                                                         | 线程                                    |
| -------------- | ------------------------------------------------------------ | --------------------------------------- |
| 直接创建对象   | multiprocessing.Process类的对象                              | threading.Thread类的对象                |
| 继承方式       | 继承multiprocessing.Process类，重写run方法                   | 继承threading.Thread类，重写run方法     |
| 池方式         | multiprocessing.Pool类                                       | concurrent.futures.ThreadPoolExecutor类 |
| 池提交任务方式 | map                                                          | map                                     |
|                | apply                                                        | 无                                      |
|                | apply_async                                                  | submit                                  |
| 共享数据       | 默认进程之间不直接共享数据                                   | 直接共享，但是需要加锁                  |
|                | multiprocessing.Queue()队列（不支持池）                      | 无                                      |
|                | multiprocessing.Manager().Queue()（支持池和非池），但是非池的任务要注意顺序或加信号量控制 | 无                                      |
|                | multiprocessing.Pipe                                         | 无                                      |
| 多进程切换成本 | 消耗高                                                       | 消耗低                                  |
